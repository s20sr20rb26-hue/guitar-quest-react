# 曲・スキルデータの編集方法

データの正本は次の2ファイルです。ExcelまたはGoogleスプレッドシートで編集できます。

- `data/songs.csv`: 曲データ
- `data/skills.csv`: スキル名とカテゴリ

## skills.csv

| 列 | 内容 |
| --- | --- |
| `No` | スキルの固定ID |
| `スキル名` | 曲データから参照する正式名称 |
| `カテゴリ` | スキル一覧で使う分類 |

カテゴリは次の5種類です。

- 基礎
- リズム・バッキング
- リード・テクニック
- ジャンル・語彙
- アンサンブル・音作り

既存の `No` は変更・再利用しません。スキル名を変更する場合は、`songs.csv` の「主スキル」「必須スキル」「習得スキル」も同じ表記へ変更してください。

## songs.csv

| 列 | 内容 |
| --- | --- |
| `No` | 練習記録との紐付けに使う固定ID |
| `曲名` | 曲名 |
| `アーティスト` | アーティスト名 |
| `演奏難易度` | 1〜10 |
| `エチュード適性` | 1〜5 |
| `ジャンル定番度` | 1〜5 |
| `カテゴリ` | アプリのコース・大分類 |
| `ルーツ` | 曲調や音楽的な系統 |
| `主スキル` | 曲で中心になる演奏スキル |
| `必須スキル` | 練習前にあるとよいスキル |
| `習得スキル` | 曲を通して身につくスキル |

## 基本ルール

- 既存の `No` は変更・再利用しません。
- 新しい行は末尾に追加し、未使用の新しい `No` を付けます。
- 表記は完全一致させます。
- CSVに定義された列以外は追加しません。
- `src/data/generatedSongs.ts` と `src/data/generatedSkills.ts` は直接編集しません。

## アプリへ反映する

```bash
npm run data:check
npm run data:build
npm run typecheck
```

通常の `npm run build` でも、先に両方のCSVからアプリ用データを自動生成します。
