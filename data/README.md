# 曲データの編集方法

曲データの正本は `data/songs.csv` です。ExcelまたはGoogleスプレッドシートで編集できます。

## 基本ルール

- `No`は練習記録との紐付けに使う固定IDです。既存の番号は変更・再利用しません。
- 新しい曲は末尾に追加し、未使用の新しい`No`を付けます。
- `演奏難易度`は1〜10、`エチュード適性`と`ジャンル定番度`は1〜5で入力します。
- `推奨ルート`はアプリにある選択肢と完全に同じ表記を使います。
- 複数のスキルは全角の`・`で区切ります。
- `次候補No`には移動先の曲の`No`を入力します。`次候補曲名`は確認用です。
- `src/data/generatedSongs.ts`は自動生成ファイルなので直接編集しません。

## アプリへ反映する

```bash
npm run songs:check
npm run songs:build
npm run typecheck
```

`songs:check`は、番号の重複、必須項目の空欄、難易度の範囲、存在しない次候補、URL形式などを検査します。

## 修正候補

`data/song-review.csv`に表記・分類・不足情報の修正候補をまとめています。確認できた行は`状態`を`採用`または`見送り`へ変更し、採用した内容を`songs.csv`へ反映します。
