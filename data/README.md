# 曲データの編集方法

曲データの正本は `data/songs.csv` です。ExcelまたはGoogleスプレッドシートで編集できます。

## 列構成

| 列 | 内容 |
| --- | --- |
| `No` | 練習記録との紐付けに使う固定ID |
| `曲名` | 曲名 |
| `アーティスト` | アーティスト名 |
| `演奏難易度` | 1〜10 |
| `エチュード適性` | 1〜5 |
| `ジャンル定番度` | 1〜5 |
| `カテゴリ` | アプリのコース・大分類 |
| `ルーツ` | 曲調や音楽的な系統 |
| `主スキル` | 曲で中心になる演奏スキル |
| `必須スキル` | 練習前にあるとよいスキル |
| `習得スキル` | 曲を通して身につくスキル |

## 基本ルール

- 既存の `No` は変更・再利用しません。
- 新しい曲は末尾に追加し、未使用の新しい `No` を付けます。
- `カテゴリ` と `ルーツ` は表記をそろえます。
- この11列以外は追加しません。
- `src/data/generatedSongs.ts` は自動生成ファイルなので直接編集しません。

## アプリへ反映する

```bash
npm run songs:check
npm run songs:build
npm run typecheck
```

通常の `npm run build` でも、先にCSVから曲データを自動生成します。
